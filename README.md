# HRMS.Command Product Website

A standalone React + TypeScript + Vite + Tailwind CSS marketing/product showcase for HRMS.Command.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- This is a separate frontend project; it does not modify or connect to the existing HRMS application.
- Product screens and numeric indicators are illustrative mockups/demo data, not live HRMS data.
- The demo request form currently provides a client-side preview confirmation only. Connect a backend/API or form provider before production use.
- Payroll language is intentionally limited to preparation and configured statutory data; validate statutory calculations and compliance before making compliance claims.
- Replace illustrative UI previews with approved, sanitized screenshots from the live HRMS when available.
